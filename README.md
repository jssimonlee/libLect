# 📚 화성시 도서관 강좌 검색 서비스 (libLect)

> 화성시통합예약시스템 OpenAPI 기반 강좌 및 교육 프로그램을 실시간으로 조회하고 필터링할 수 있는 반응형 웹 애플리케이션입니다.

---

## ✨ 최근 업데이트 사항 (AI 협업 개선)

최근 다른 AI와 협업하여 사용자 경험(UX)과 검색 효율성을 대폭 개선한 최신 기능 업데이트 목록입니다.

### 1. 🏛️ 도서관 중심 기관 필터링
- 기관 선택 목록(`institutionSelect`)에 **"도서관"** 명칭이 포함된 전문 도서관 기관만 표시되도록 정제하여 필터의 노이즈를 없앴습니다.

### 2. 🔍 초정밀 통합 검색 (Full-text Search)
- 단순히 기관명에 국한되지 않고, **강좌명, 기관명, 대상, 장소, 문의처, 무료 여부** 등 데이터 내 모든 필드를 아우르는 통합 검색 시스템을 도입했습니다. 
- 단어 검색 하나로 대상층(예: 초등, 실버)이나 수강료 정보(예: 무료)까지 손쉽게 검색할 수 있습니다.

### 3. 🎨 파스텔 톤 필터 UI & 초소형(Compact) 최적화
- 상단 상태 필터 버튼들을 눈이 편안한 **작고 귀여운 파스텔 톤** 디자인 테마로 개편했습니다.
- 특히, 사용성 향상을 위해 버튼의 전체 면적을 기존 대비 약 **절반 수준(Padding 0.18rem 0.45rem, 글자 크기 0.65rem)**으로 아주 콤팩트하게 잘게 조절하여 화면 공간을 훨씬 덜 차지하도록 디자인했습니다.
- 마우스 호버 및 액티브 시 부드러운 전환 효과(Transition)와 시각적 안정감을 제공합니다.

### 4. 📊 검색 결과 기반 실시간 개수 표시 (Dynamic Badge)
- 각 필터 버튼 라벨에 현재 검색 결과를 기준으로 한 개수를 실시간으로 계산하여 표시합니다.
  - 예: `전체(15)`, `오늘수업(3)`, `접수중(8)` 형식
- 사용자는 탭을 전환하지 않고도 각 상태별로 몇 개의 강좌가 매칭되었는지 직관적으로 알 수 있습니다.

### 5. 💡 오늘 수업 카드 형광 녹색 Glow 효과
- 오늘 진행되는 수업이 있는 카드는 테두리를 강조하고 **형광 녹색 Glow(빛나는 효과)** 애니메이션 그림자 효과를 적용하여 사용자 시선을 사로잡을 수 있도록 디자인을 강화했습니다.

### 6. 🌈 강좌 상태별 컬러 테마 최적화
- 강좌 접수 상태에 따라 카드의 왼쪽 보더(Border) 및 상태 배지에 각기 다른 세련된 컬러 코드를 부여하여 가독성을 향상시켰습니다.
  - **접수중**: 싱그러운 에메랄드 그린 🟢
  - **접수예정**: 차분한 스카이 블루 🔵
  - **접수마감**: 주의가 필요한 소프트 레드 🔴
  - **강좌종료**: 심플하고 단정한 클래식 그레이 ⚪

### 7. ⚡ 도서관 선택 시 실시간 반응형 동기화
- 사용자가 도서관 셀렉트 박스에서 특정 도서관을 선택하면, 별도의 검색 버튼을 누르지 않아도 **오늘수업/접수중/접수예정 등의 상태별 개수와 리스트가 즉시 자동 갱신**됩니다.

### 8. 💾 선택한 도서관 자동 기억 (localStorage 활용 영속화)
- 사용자가 도서관 목록에서 특정 도서관을 선택하면 이력이 브라우저의 `localStorage`에 즉시 저장됩니다.
- 다음에 사용자가 사이트를 다시 열었을 때 자동으로 이전에 선택했던 도서관이 선택되며, 해당 도서관의 강좌 목록이 즉시 화면에 노출되어 매번 다시 선택하는 번거로움을 완전히 해결했습니다.

### 9. 🏛️ 화성시문화관광재단 도서관사업팀 특별 격리 및 시각적 분리
- 기관 드롭다운에서 일반 도서관과 비도서관 기관(도서관사업팀)을 구분하기 위해 가나다순으로 정렬된 일반 도서관 목록 아래에 구분선(`────────────────────`)을 긋고 그 아래에 단독 배치하였습니다.
- 전체도서관 상태이거나 키워드 통합 검색 시에는 도서관사업팀의 강좌가 결과에 노출되지 않도록 처리하고, 사용자가 드롭다운에서 명시적으로 **"화성시문화관광재단 도서관사업팀"**을 골라서 검색을 수행했을 때만 전용 강좌들이 노출되도록 격리 작동 로직을 구현했습니다.

### 10. ⛔ "전질대출" / "전질 대출" 불필요 강좌 원천 차단
- 강좌명이나 상세 정보 등 텍스트 내에 "전질 대출" 또는 "전질대출" 문구가 포함된 강좌는 OpenAPI를 수집하는 **최초 서버 및 Cloudflare Worker 단계에서부터 캐시 데이터셋에 수집하지 않도록 전량 스킵** 처리했습니다.
- 브라우저에 이미 저장되어 있을 수 있는 기존 로컬 스토리지의 구형 캐시까지 방어하기 위해 클라이언트 로딩 시점, API 병합 시점 및 최종 검색 시점까지 삼중 방어 필터를 적용하여 검색 결과에서 완전히 배제시켰습니다.

## ☁️ Cloudflare Worker 배포 방법

이 프로젝트의 API 프록시 및 최적화 캐시 엔진인 `worker.js`를 Cloudflare Workers 서비스로 배포하는 과정입니다.

배포하는 방법은 크게 두 가지가 있으며, **"대시보드 웹사이트에 직접 붙여넣는 방법"**이 현재 사용 중인 가장 보편적이고 편리한 방식입니다.

### 방법 1. Cloudflare 웹 대시보드에서 직접 코드를 붙여넣어 배포 (현재 사용 방식)

별도의 CLI 개발 도구 설치나 로그인 세션 만료 등의 에러 우려 없이, Cloudflare 콘솔 웹사이트에서 가장 직관적이고 빠르게 코드를 업데이트할 수 있는 현재 권장 배포 방법입니다.

1. **코드 복사**: 
   - 로컬 작업 디렉토리의 [worker.js](file:///C:/Users/user/Documents/python/libLect/worker.js) 파일 전체 내용을 선택하여 복사합니다 (`Ctrl + A` ➔ `Ctrl + C`).
2. **Cloudflare 관리자 페이지 접속**:
   - [Cloudflare 대시보드 (dash.cloudflare.com)](https://dash.cloudflare.com/)에 로그인합니다.
3. **Worker 프로젝트 진입**:
   - 왼쪽 사이드바 메뉴에서 **Workers & Pages** ➔ **Overview**를 선택한 후, 배포할 도서관 API 프록시 Worker 서비스를 찾아 클릭합니다.
4. **웹 에디터(Quick Edit) 열기**:
   - 우측 상단 영역에 있는 **Edit Code** (또는 **Quick Edit**) 파란색 버튼을 클릭하여 웹 전용 소스코드 에디터 창을 실행합니다.
5. **소스코드 붙여넣기 및 최종 배포**:
   - 기존 웹 에디터 화면에 채워져 있던 기존 코드를 모두 선택하여 지운 뒤, 1단계에서 복사해 온 최신 `worker.js` 코드 전체를 붙여넣습니다 (`Ctrl + A` ➔ `Delete` ➔ `Ctrl + V`).
   - 우측 상단의 **Save and deploy** (저장 및 배포) 버튼을 클릭한 뒤, 안내 팝업창에서 한 번 더 배포 버튼을 눌러 승인합니다.
   - 단 1초 만에 전 세계 엣지 네트워크 서버에 변경 데이터(전질대출 배제 필터 등)가 완벽하게 실시간 반영됩니다.

### 방법 2. Wrangler CLI 도구를 사용하여 터미널에서 배포 (개발자 CLI 방식)

1. **Wrangler CLI 도구 세션 로그인**:
   ```bash
   npx wrangler login
   ```
2. **배포 명령어 실행**:
   ```bash
   npx wrangler deploy worker.js
   ```
   *(환경 설정 및 설치 버전에 따라 `npx wrangler publish` 명령이 요구될 수 있습니다.)*
